# PrezzoVeroAlimentare

Prototipo HTML statico per consultare prezzi alimentari pubblici e rilevati, con fonte, data, mercato/origine e livello di verificabilità.

## Demo online

Il prototipo è consultabile qui:

https://thunajack.github.io/PrezzoVeroAlimentare/

## Obiettivo

PrezzoVeroAlimentare serve per farsi un’idea veloce e orientativa dell’ordine di grandezza dei prezzi alimentari.

Non indica dove conviene fare la spesa e non stabilisce il “prezzo giusto”.  
Ogni dato va letto insieme a:

- fonte;
- data di rilevazione;
- mercato/origine;
- fase della filiera;
- livello di verificabilità.

## Verificabilità delle fonti

I dati sono classificati in tre livelli:

- Fonte pubblica verificabile: listino, banca dati, PDF o pagina pubblica linkabile.
- Fonte dichiarata: supermercato, macelleria, pescheria, mercato, scontrino o volantino non linkabile.
- Fonte mancante: dato inserito manualmente senza provenienza chiara.

I dati senza fonte non dovrebbero entrare nei riepiloghi principali, salvo scelta esplicita dell’utente.

## Stato

Versione dimostrativa con dati demo interni al file `index.html`.

## Uso

Aprire `index.html` nel browser oppure pubblicare la cartella con GitHub Pages.

## Nota importante

I prezzi attualmente presenti nel prototipo sono dimostrativi e non devono essere interpretati come dati reali aggiornati.
Prima della pubblicazione reale, sostituire i dati demo con fonti verificabili e controllare licenze/condizioni d’uso delle fonti.
